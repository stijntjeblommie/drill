# Morning Drill

iPhone-friendly quant mental-math drill with trick-of-the-day, exercise timers, and Shortcuts hooks.

**Live URL:** https://stijntjeblommie.github.io/drill/

## iPhone setup

1. Open the URL in **Safari** → Share → **Add to Home Screen**.
2. Shortcuts → Automation → Alarm → *Is Stopped* → Run Immediately → **Open URLs** → paste the link above.
3. Create a shortcut named exactly **Morning Done** that toggles off your backup alarm.
4. Create a shortcut named exactly **Drill Done** that saves a completion timestamp (optional unlock flow).

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080 --directory .
```
